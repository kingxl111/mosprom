## Требуемые переменные окружения

Создайте файл `.env` со следующими переменными:

```env
# Database Configuration
DATABASE_HOST=localhost
DATABASE_PORT=5432
DATABASE_NAME=auth_service
DATABASE_USER=postgres
DATABASE_PASSWORD=password

# HTTP Server Configuration
HTTP_HOST=localhost
HTTP_PORT=8081

# Logger Configuration
LOGGER_LEVEL=debug

# JWT Secret (ОБЯЗАТЕЛЬНО ИЗМЕНИТЕ В ПРОДАКШЕНЕ!)
JWT_SECRET=your-super-secret-jwt-key-change-in-production
```

## Запуск проекта

1. Установите зависимости:
```bash
go mod tidy
```

2. Создайте базу данных PostgreSQL и выполните миграции:
```bash
# Создайте базу данных
createdb auth_service

# Выполните миграции
psql -d auth_service -f migrations/000001_init.up.sql
```

3. Создайте файл `.env` с настройками

4. Запустите сервер:
```bash
go run cmd/server/main.go
```

## Важные замечания по безопасности

1. **JWT Secret**: Обязательно измените JWT_SECRET в продакшене на криптографически стойкий ключ
2. **Пароли**: Теперь используются bcrypt с солью для хеширования паролей
3. **Токены**: Refresh токены генерируются с использованием crypto/rand
4. **Валидация**: Добавлена базовая валидация входных данных
